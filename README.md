# Beso Loom｜剧情织机

Beso Loom 是一个 SillyTavern 第三方剧情引导扩展。

它不是替你随机导演主线的系统。你负责决定故事最终要经过哪些关键节点，正文模型负责人物、NPC、日常、小事件、台词和过渡；Beso Loom 在幕后定期巡检，只有确认当前阶段已经实际完成时才推进到下一节点。

## v0.1.0 做什么

- 一行一个“大节点”保存完整剧情脉络。
- 也可以粘贴整段大纲，让当前 SillyTavern 模型静默粗拆成少量大节点。
- 默认每 5 个 AI 回复巡检一次；5 轮只是检查频率，不是强制推进节拍。
- 幕后监督只判定：进行中 / 已完成 / 偏航。
- 只有“已完成”才自动前进，而且一次最多前进一步。
- 正文模型只收到当前阶段目标，不收到完整未来路线。
- 偏航时只注入轻量纠偏，不替用户写正文，也不替用户角色做决定。
- 支持手动上一节点、下一节点、立即巡检。
- 支持宽松 / 平衡 / 严格三档监督尺度，默认平衡。
- 支持可选“硬限制”，不要求日常填写。
- 每个聊天单独保存自己的剧情路线和当前节点。

## 安装

在 SillyTavern 的第三方扩展安装界面输入：

`https://github.com/besoecho/besoloom`

安装完成后刷新 SillyTavern，在 Extensions 设置中找到 **Beso Loom｜剧情织机**。

## 最简单的用法

1. 打开准备跑剧情的聊天。
2. 在“完整剧情脉络”里一行写一个大节点。
3. 点击“保存线路”。
4. 保持默认的“每 5 轮巡检 + 平衡”即可开始跑卡。
5. 想立刻检查时点“立即巡检”；需要人工纠正进度时使用“上一节点 / 下一节点”。

如果手里是一整段长大纲，不想自己分节点，把全文贴进去后点击“AI 粗拆节点”。粗拆只整理现有主线，不应该替你新增关键剧情。

## 设计原则

你决定“去哪里”，模型决定“这一路怎么走得像真的”。

完整路线只存在于聊天 metadata 和幕后监督提示中；正文注入只包含当前阶段、硬限制和必要的轻量纠偏。这样既保留剧情方向盘，也尽量不给正文模型剧透未来。

## 当前版本边界

v0.1.0 先追求能装、能跑、够简单。UI 和监督规则会根据实际跑卡体验继续调整。

本项目参考了 Arrebol D / 小红霞的 SillyTavern 扩展管线思路，但剧情控制逻辑按 Beso Loom 的目标重新实现。
